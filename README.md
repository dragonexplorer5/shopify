This project is an AI-Powered shopping assistant built with Electron and made to help users find the best deals across multiple retailers. It uses Google Gemini to understand user queries and analyze product information for price, quality, and value. The app is designed to be a life saver for shopper looking for the best deal without having to manually search through multiple websites.

# Features
- Natural language understanding with Google Gemini
- Multi-retailer product search
- Price, quality, and value analysis
- User-friendly interface

# Future Enhancements
- Allow for image input to find similar products
- Add user accounts and preferences
- Implement real-time price tracking and alerts
- Add emailme to notify users of price drops or deals
